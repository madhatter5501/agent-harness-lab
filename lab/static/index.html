              What this demo guarantees—and what it does not
              

                API authorization, schema validation, execution limits, and
                write approval are enforced by code. Supported order and policy
                answers are rendered from checked API fields. General
                conversation is not independently fact-checked. The identity
                selector is a local demonstration, not production login. Audit
                records contain request data; they omit credentials and are not
                tamper-proof. Byte sizes are measurements, not token estimates.
                Mock mode is a scripted fixture.
